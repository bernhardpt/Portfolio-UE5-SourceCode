# Huge Hordeal - C++ Source Code

## 📖 About The Project
This repository contains the C++ source code for **Huge Hordeal**, a post-apocalyptic Zombie Horde Shooter developed in Unreal Engine 5. 

This project was developed as the final project for the Unreal Engine 5 development course at Tokio School. The code provided here serves as a portfolio showcase, demonstrating my ability to architect and implement core gameplay systems, artificial intelligence, and user interfaces using C++.

## 🛠️ Core Systems Implemented in C++

The files in this repository contain the logic for the following systems:

* **Wave & Spawn Management:** Dynamic enemy spawning logic, wave progression tracking, and difficulty scaling.
* **AI & Behavior Trees:** Custom AI Controllers for enemies, integrating patrol and chase states using UE5's Behavior Trees and Blackboards.
* **Combat & Projectiles:** Implementation of physical projectile-based shooting mechanics, hit detection, and damage application.
* **Enhanced Input System:** Integration of UE5's modern input framework for responsive character movement and actions.
* **Survival Attributes:** Core player components for managing health, stamina, and death states.
* **Data Persistence & Leaderboards:** A save/load framework to maintain game state, track high scores, and manage leaderboards.
* **UI/HUD Integration:** C++ backend logic exposed to Unreal Motion Graphics (UMG) to provide real-time player feedback (health bars, current wave, score).

## 💻 Technologies & Tools
* **Engine:** Unreal Engine 5
* **Language:** C++
* **Architecture:** C++ base classes extended and visualized via Blueprints (Animation Blueprints, UMG).

## 📂 Repository Structure
As this repository is intended to showcase my programming and architecture skills, it contains only the C++ header (`.h`) and source (`.cpp`) files from the `Source` folder. Large project assets (3D models, textures, engine binaries) are intentionally omitted to keep the repository clean and focused on code evaluation.
